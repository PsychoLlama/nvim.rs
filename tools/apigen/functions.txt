# Every method the msgpack-RPC dispatcher answers to. tools/apigen generates
# a wrapper per entry and the handler table from all of them; everything else
# about a wrapper is read off the Rust signature in crates/nvim/src/nvim/api/.
#
#   <name> [flag ...] [key=value ...]
#
# Flags — upstream's FUNC_API_* markers, which the transpile did not carry
# into the Rust tree:
#
#   textlock               refuse while the text is locked
#   textlock_allow_cmdwin  refuse under textlock, tolerate the cmdline window
#   fast                   may run straight from the RPC read callback
#                          instead of being deferred to the main loop
#   ret_alloc              the result is heap-allocated for the caller to
#                          free, rather than owned by the request arena
#
# Keys:
#
#   argN=<type>  the declared type name to name in a "Wrong type for argument
#                N" message, for parameters whose C declaration carried a
#                decoration Rust cannot express (ArrayOf(Integer, 2) is a
#                plain Array here). Underscores stand for spaces.
#   alias=<name> this method is a deprecated spelling of <name>: it shares
#                that method's wrapper and inherits its fast/ret_alloc.
#   handler=<p>  the handler is hand-written at crate path <p>.
#
# Entries with alias= or handler= get no wrapper of their own. The rest are
# grouped by the API source file, which is also how the generated modules
# are split.
